DOSSIER FONTS — PASTRAMI
=========================

Place ici tes fichiers Pastrami pour activer la police sur le portfolio :

  fonts/Pastrami.woff2   (format prioritaire)
  fonts/Pastrami.woff    (fallback)

La declaration @font-face est deja dans styles/main.css.
En attendant, la police de substitution est "Cormorant Garamond"
(chargee via Google Fonts), qui a un style serif similaire.
